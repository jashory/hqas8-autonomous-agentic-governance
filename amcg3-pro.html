Technical & security FAQ

Does the open adapter or Pro runtime send source code or telemetry to external servers?

No. Both the Apache-2.0 open adapter and the closed-core AMCG-3 Pro runtime execute 100% locally. Offline RSA-2048 license keys verify locally with Python built-in modular exponentiation without phone-home calls, and no secrets, .env files, or SSH keys are ever read.

What is the exact boundary between the open GitHub repo and the commercial core?

The public repository (jashory/grok-build-amcg3-guard, submitted to xAI Plugin Marketplace in PR #2201) ships strictly the lightweight hook adapter for encrypted-PDF blocking, worktree SHA-256 diff verification, and environment deduplication. The Byte-Bounded UTF-8 Compaction Digest engine (-98.9%), Asymmetric Planner-Executor Orchestrator (-85% frontier token burn), 4-Tier Supervisor Turn-Lock, and Split-Brain Live Voice Bus remain proprietary commercial IP.
